# docs/

Put the demo recording here as `demo.gif`, then uncomment the DEMO block near the
top of `README.md` and `README.zh-CN.md`.

What the recording has to show, in this order and nothing else:

1. a session mid-turn, working;
2. the stream drops and `API Error: Connection lost mid-response` appears;
3. about a second later the retry is typed into that same terminal, by nothing
   visible;
4. the turn continues.

Keep it under 30 seconds and under 5 MB — GitHub will not autoplay anything
larger and readers will not wait. Crop to the terminal; no desktop, no editor, no
title card.
